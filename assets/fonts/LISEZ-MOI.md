# Polices incluses dans Omni-Agenda

Ces polices sont copiées dans l'application pour qu'elle fonctionne **sans internet**.
Toutes sont sous licence libre **SIL Open Font License 1.1** : elles peuvent être
utilisées, copiées et distribuées avec une application, gratuitement. Le texte complet
de chaque licence se trouve dans le dossier `licences/`.

| Police | Fichiers | Droits d'auteur | Particularité |
|---|---|---|---|
| Atkinson Hyperlegible | `atkinson-400.woff2`, `atkinson-700.woff2` | Braille Institute of America, Inc. | Lettres très distinctes, pour les personnes malvoyantes |
| Lexend | `lexend-400.woff2`, `lexend-700.woff2` | The Lexend Project Authors | Espacée, pour faciliter la lecture |
| OpenDyslexic | `opendyslexic-400.woff2`, `opendyslexic-700.woff2` | Abbie Gonzalez | Pensée pour les personnes dyslexiques |
| Andika | `andika-400.woff2`, `andika-700.woff2` | SIL International | Lettres simples, comme apprises à l'école |
| Literata | `literata-400.woff2`, `literata-700.woff2` | The Literata Project Authors | Style livre, avec empattements |
| Nunito | `nunito-400.woff2`, `nunito-700.woff2` | The Nunito Project Authors | Arrondie et douce |
| Patrick Hand | `patrick-hand-400.woff2` | Patrick Wagesreiter | Écriture manuscrite |

Origine des fichiers : paquets « @fontsource » (version 5.3.0), jeu de caractères
« latin » (qui couvre tout le français : accents, ç, œ, guillemets « », €).
